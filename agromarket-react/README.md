# АгроМаркет — Лабораторная работа №3

React-версия каталога из лабораторной работы №2.

## Что реализовано

- переиспользуемый компонент `ProductCard`, получающий данные через props;
- загрузка товаров с `json-server` при помощи `useEffect`;
- хранение товаров, строки поиска и счётчика корзины в `useState`;
- управляемое поле поиска с фильтрацией без перезагрузки;
- состояния загрузки, ошибки и пустого результата поиска;
- увеличение счётчика корзины через функцию, переданную карточке в props.

## Запуск

Нужен Node.js 20 или новее.

1. Откройте терминал в папке `agromarket-react` и установите зависимости:

   ```bash
   npm install
   ```

2. В этом же терминале запустите сервер данных:

   ```bash
   npm run server
   ```

3. Откройте второй терминал в папке `agromarket-react` и запустите React:

   ```bash
   npm run dev
   ```

4. Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сервер данных использует файл `../agromarket/db.json` и работает по адресу
`http://localhost:3001/products`.
