# Лабораторная работа №3 — быстрый запуск

В архиве находятся две папки:

- `agromarket` — исходная лабораторная №2 и файл `db.json`;
- `agromarket-react` — готовая лабораторная №3 на React.

## Первый запуск

Откройте папку `agromarket-react` в VS Code. Убедитесь, что установлен
Node.js 20 или новее. Затем выполните:

```bash
npm install
```

## Обычный запуск

Откройте два терминала VS Code. Оба терминала должны находиться в папке
`agromarket-react`.

Терминал 1 — сервер с товарами:

```bash
npm run server
```

Терминал 2 — React-приложение:

```bash
npm run dev
```

Откройте адрес из второго терминала, обычно `http://localhost:5173`.

## Что проверить перед сдачей

1. Отображаются четыре товара из `agromarket/db.json`.
2. Поиск `мол` оставляет карточку молока.
3. Поиск не зависит от регистра букв.
4. Кнопка «В корзину» увеличивает счётчик в шапке.
5. После остановки первого терминала и обновления страницы появляется
   понятное сообщение об ошибке.

## Короткие ответы для защиты

**Что такое props?** Props — это данные, которые родительский компонент
передаёт дочернему. `App` передаёт товар и функцию `onAdd` компоненту
`ProductCard`.

**Что такое state?** State — изменяемые данные компонента. В `App` через
`useState` хранятся товары, поисковая строка, счётчик корзины, загрузка и
ошибка. Изменение state заставляет React обновить интерфейс.

**Зачем `[]` в `useEffect`?** Пустой массив зависимостей означает, что эффект
нужно выполнить после первого появления компонента, а не после каждого его
обновления. Поэтому товары не запрашиваются снова при вводе текста или клике
по кнопке.

**Что такое controlled input?** Это поле, значение которого хранится в state.
`value={searchTerm}` показывает текущее состояние, а `onChange` обновляет его
при вводе.

**Зачем нужен `key`?** `key={product.id}` помогает React однозначно различать
карточки при обновлении списка.

**Почему счётчик находится в `App`?** Он общий для всех карточек. Карточки
только сообщают родителю о нажатии через `onAdd`. Это называется поднятием
состояния вверх.
